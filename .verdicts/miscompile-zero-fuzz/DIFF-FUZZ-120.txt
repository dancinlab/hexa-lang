METHOD
------
For each deterministic-seeded random hexa program (seed -> identical .hexa
via an LCG, no platform RNG), three differential axes vs the C oracle:

  axis 1  --emit=asm  : byte-diff modulo the documented benign per-module
                        label hash __L<sha4>_  (canonicalized to __L_HASH_).
  axis 2  --emit=obj  : gen2 must emit 0 "ENCODE-MISS", 0 spurious/unresolved
                        udf, and a non-empty .o.
  axis 3  behavior    : link both .o with the runtime, compare process exit
                        codes (8-bit mask applied identically on both sides).

Generated feature surface (all proven to compile+run on BOTH compilers):
  i64 + hex-literal arithmetic (+ - *), guarded / and %, comparison chains,
  if/else, counter-bounded while loops, array literals + indexing,
  match-expressions (`->` arms), 1..3 helper functions incl. nested calls,
  recursion-safe call graph. (for-in ranges and float-heavy paths are
  deliberately excluded — snapshot-fragile parse, not codegen, surface.)
