METHOD
------
Identical 3-axis differential harness as DIFF-FUZZ-120, now with the opt-in
STRING lane enabled (env DIFF_FUZZ_STR=1). Each deterministic-seeded random
hexa program (seed -> identical .hexa via an LCG, no platform RNG) is checked
on three axes vs the C oracle:

  axis 1  --emit=asm  : byte-diff modulo the documented benign per-module
                        label hash __L<sha4>_  (canonicalized to __L_HASH_).
  axis 2  --emit=obj  : gen2 must emit 0 "ENCODE-MISS", 0 spurious/unresolved
                        udf, and a non-empty .o.
  axis 3  behavior    : link both .o with the runtime, compare process exit
                        codes (8-bit mask applied identically on both sides).

NEW STRING SURFACE (the 2-register ptr,len string-value ABI) — all idioms
pre-probed compiling+running on the shipped hexa:
  * string literals (short words: "hex" "ab" "go" "ok" "fn" "let" ...)
  * `+` string concat:  ("a" + "b")  (pure-string, recursively nested)
  * len(s) -> i64       (folds into the int scope / exit accumulator)
  * s == s in an `if`   (string equality -> 0/1 i64)
All string outcomes fold into the existing i64 exit-code differential.
Strings stay PURE — never mixed with int operands (hexa has no
auto-promotion, so a mixed `+` would be an invalid program, not a signal).

This lane probes the historically-fragile native-codegen surface flagged in
CC-NATIVE: miscompile_class m3 (_ends_with / == cascade) and m4 (two-register
value ABI). The #2565 widening covered float/struct/closure but NOT strings;
this verdict extends the CLEAN frontier to the 2-reg string ABI.

The string lane is env-gated and INDEPENDENT of the float lane. With
DIFF_FUZZ_STR unset the generator output is BYTE-IDENTICAL to the pre-string
baseline (no extra rng draws, no wider kind range): verified seed 7 sha
unchanged (9f113f4c1506882b...) and seeds 1..20 byte-identical to HEAD, so the
existing 1..120 / 1..500 CLEAN baselines reproduce exactly.

canonicalized asm diff / encode log / exit pair, so any future string-ABI
miscompile is reported with an immediate minimal repro. Extend coverage by
widening the seed range (e.g. `DIFF_FUZZ_STR=1 bash tool/diff_fuzz.sh 151 500`).
