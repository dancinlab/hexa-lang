═══ ADDENDUM 2026-06-14 — SHIP-BY-DEFAULT (edge-roll) + darwin-loop ROOT CAUSE ═
branch: ship/n5-seed-converge-default   host: ghost (darwin-arm64) + summer (x86_64)

The opt-in HEXA_SEED_CONVERGE=1 (00b7f45e2 / #3338) had been made opt-in because
the convergence loop "failed on darwin-arm64 with exit 1" in the shared
release_build path. ROOT CAUSE (reproduced on ghost AND summer — NOT darwin-
specific, NOT BSD-vs-GNU): the loop's TRAILING statement was

    [ "$i" -ge "$max" ] && echo "...WARN..." >&2

As the LAST command in stage_prebuild_hexat, on the normal FIXPOINT path
($i < $max) the bare `[ … ]` test returns 1, which BECOMES the script's exit
code. release_build runs under `set -e`, so that exit 1 aborts the whole build —
on every platform. (It "passed" in the prior summer verdict only because that
test ran the loop in isolation, not through release_build's set -e.)

FIX (tool/stage_prebuild_hexat): convert the trailing `[..] && echo` to a proper
`if`, then `test -x "$HEXAT"; exit 0` so a converged build is unambiguously
successful. Verified: bash tool/stage_prebuild_hexat → EXIT 0 at FIXPOINT
(was 1); full release_build → "[release_build] PASS" on BOTH ghost (darwin-arm64)
and summer (linux-x86_64).

tool/release_build, NOT in nobaseline-gate.yml (faithful). Faithful edge-pulls
