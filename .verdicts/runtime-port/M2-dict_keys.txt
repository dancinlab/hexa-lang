CASE COVERAGE
------------------------------------------------------------------------
  empty       : len 0, both paths empty array.
  one         : single key.
  many        : strict insertion order across mixed key names.
  overwrite   : re-insert existing key x (twice) + y (once) -> order
                UNCHANGED [x][y], NO duplicate (dedup-on-overwrite proven).
  forty       : 40 numeric-string keys 0..39 — collision-stress, exact
                insertion order preserved.
  mix         : interleaved insert + overwrite — overwrites neither move
                nor duplicate the order entry.
  nul         : embedded-NUL key handled bit-identically on both paths
                (pre-existing C-rep NUL-termination inherited, not changed).
