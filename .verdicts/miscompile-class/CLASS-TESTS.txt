DISCRIMINATION PROOF (g63 honesty — the tests actually catch a regression)
--------------------------------------------------------------------------
Negative control: assert `(0xff & 0xf0) == 0` (the COLLAPSED/regressed value).
  gen2_fix -> printed CORRECT, rc=99 (hex did NOT collapse). A regressed
  compiler would have printed COLLAPSED rc=0 -> the assert discriminates.
Tamper control: a copy of m1 with the expected value mutated 240 -> 999.
  Runner -> "FAIL  m1_hex_literal — RUN rc=51 (wrong runtime value -> CLASS
  REGRESSED)", RUNNER-EXIT=1. The runner returns nonzero and names the class
  on any value mismatch (no pipe-mask, real exit codes).

CI-WIRING NOTE (for the gate agent; NOT done here, gates untouched)
-------------------------------------------------------------------
This runner is additive and standalone. A future CI step could invoke
`self/test/miscompile_class/run.sh` with HEXA_NATIVE_CC pointed at the
graduated gen2 and HEXA_RUNTIME at self/runtime.c, gated identically to
miscompile_zero_gate.sh (exit 2 = infra/no-native-emitter = CI-neutral;
exit 1 = real class regression). It complements (does not replace) the
program-level tool/miscompile_zero_gate.sh.
