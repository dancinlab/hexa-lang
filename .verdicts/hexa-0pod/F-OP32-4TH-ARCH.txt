4th ARCHITECTURE (new primitive class — none shared with the 3 proven archs)
  A spiking Leaky-Integrate-and-Fire (LIF) RECURRENT network with local
  pair-based STDP plasticity (the production spiking_lib substrate), plus the
  production plasti_sim competitive-Hebbian learner:
    x_t[D] ─Win→ I[i] ─(+ Wrec·s_prev recurrent)→ leaky integrate (α·v + I,
    refractory clamp) → event threshold (v ≥ v_th) → spike reset → refractory
    countdown → eligibility-trace decay → pair-STDP plastic update of Wrec →
    next step (T=32 steps, N=10 units, D=8 inputs)
  NEW DETERMINISM SURFACE — recurrence/state-threading: v, refr, tr_pre,
  tr_post, Wrec and s_prev are THREADED through T sequential steps; one
  divergent op at step t corrupts every step > t, so the final fingerprints
  are maximally order-sensitive. NEW PRIMITIVES (vs all 3 proven archs):
  event thresholding (≥ branch, F-SPIKE-1), integer refractory countdown with
  clamp (F-SPIKE-2), clip, winner-take-all argmax (plasti_sim ps_winner), and
  NON-BACKPROP local learning (pair-STDP F-SPIKE-3 + competitive Hebbian
  ps_hebb_update — event-driven plasticity, no loss, no gradient).
    - vs CLMConvMoE: no Conv1d, no MoE, no GroupNorm, no CE/softmax
    - vs decoder block: no attention, no RoPE, no SwiGLU, no RMSNorm
    - vs MLP: no dense GEMM layers, no GELU — and it LEARNS without backprop
  Config tiny CPU-runnable: N=10 · D=8 · T=32 (LIF) ; Np=6 · Dp=8 · S=24
  (plasti_sim). Deterministic init (fixed LCG seeds 2121/2222/3001/4001/7001;
  no RNG, no clock).

OP-30 MATMUL-PATH AUDIT (this arch)
  spiking_lib's production primitives are PURE t_get/t_set loops — NO
  farr_matmul, NO forge_dispatch on the CPU path → OP-30-compliant BY
  CONSTRUCTION (unlike OP-31's nn_linear_fwd which rode the fused kernel).
  The only matmul-shaped op on the arch is the per-step input/recurrent
  current I[i] = Σ_j Win[i·D+j]·x_t[j] + Σ_j Wrec[i·N+j]·s_prev[j] — computed
  INLINE in fixed ascending j (plain mul+add, no C kernel), the OP-29/30/31
  discipline. plasti_sim's ps_drive is ALREADY inline-ascending in production.
LIBM AUDIT (this arch) — clean BY CONSTRUCTION: NO transcendental anywhere on
  the path. Membrane leak and trace decays are FIXED binary-exact rational
  constants (α=15/16=0.9375 · decay_pre=7/8=0.875 · decay_post=13/16=0.8125 ·
  A±=1/32,1/64 · v_th=0.5) — the usual exp(−dt/τ) is folded into the constant,
  so no dt_* is even needed; every op is +,−,·,/ and compares on fp64.
