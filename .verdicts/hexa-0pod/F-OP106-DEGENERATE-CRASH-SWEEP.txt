THE 🔴 FIX — matrix axis-reduce degenerate empty-axis crash
-----------------------------------------------------------
FILE: stdlib/matrix/mod.hexa
CONTRACT (header L13-26): flat row-major M, explicit (m,n), axis 0 collapses rows
(out length n), axis 1 collapses cols (out length m). NO documented m≥1 / n≥1
precondition — a 0-row / 0-col (empty) matrix is a plausible degenerate input
(argmax/mean over the columns of an empty result set). The reduction along the
collapsed axis runs UNCONDITIONALLY:
  matrix_mean_axis/std_axis:  out.push(s / to_float(m))   // m==0 (axis0) → 0/0
  matrix_argmax_axis:         best_v = M[j]               // m==0 (axis0) → read M[0] on empty M

VERBATIM BOUNDARY REPRO (shipping `hexa run`, hermetic verbatim-inlined UNFIXED bodies):
  matrix_mean_axis([], 0, 3, 0):
    stdout: `mean m=0,n=3,axis=0:division by zero`
  matrix_std_axis([], 0, 3, 0):
    stdout: `std m=0,n=3,axis=0:division by zero`
  matrix_argmax_axis([], 0, 3, 0):
    stdout: `--- m=0,n=3,axis=0 (argmax over columns of an empty matrix) ---index 0 out of bounds (len 0)`
  matrix_argmax_axis([], 4, 0, 1)  (the axis-1 flavor):
    stdout: `UNFIXED argmax m=4,n=0,axis=1:index 0 out of bounds (len 0)`
  (matrix_sum_axis([], 0, 3, 0) is SAFE: `0.0` per bin — no division, the existing zeros contract.)

MINIMAL FIX (additive, 0 deletions; saturate the degenerate empty reduction axis):
  matrix_mean_axis:  out.push(if m == 0 { 0.0 } else { s / to_float(m) })   (axis 0)
                     out.push(if n == 0 { 0.0 } else { s / to_float(n) })   (axis 1)
  matrix_std_axis:   if m == 0 { out.push(0.0); j = j + 1; continue }       (axis 0, before div)
                     if n == 0 { out.push(0.0); i = i + 1; continue }       (axis 1)
  matrix_argmax_axis:if m == 0 { out.push(0); j = j + 1; continue }         (axis 0, before M[j])
                     if n == 0 { out.push(0); i = i + 1; continue }         (axis 1, before M[i*n])
  rationale: mean/std of NO elements → 0.0 (matches matrix_sum_axis's existing zeros
  and the runtime rt_array_mean empty→0.0 contract); argmax over NO elements → index 0
  (the smallest-index tie convention degenerates). OUTPUT LENGTH (n for axis 0, m for
  axis 1) is PRESERVED — same shape, saturated values, no crash.
