🔴 BUG (REAL, SHIPPING) — stdlib/alloc/path.hexa :: path_ext (+ path_stem)
--------------------------------------------------------------------------------
path_ext scanned for the last '.' with a bare `while i > 0` guard. That guard
only protected a SINGLE leading dot, so it correctly returned "" for ".bashrc"
/ ".config" but LEAKED a bogus extension when the basename began with a RUN of
dots. POSIX/Python splitext treats the whole leading dot-run as part of the
name — never an extension.

VERBATIM repro (faithful Python port of the UNFIXED body vs posixpath.splitext
on the basename):
    ext('..ext')   = '.ext'   (splitext: '')   BUG
    ext('..')      = '.'       (splitext: '')   BUG
    ext('...')     = '.'       (splitext: '')   BUG
    ext('....y')   = '.y'      (splitext: '')   BUG
    ext('a/..')    = '.'       (splitext: '')   BUG   (basename '..')
    ext('/..')     = '.'       (splitext: '')   BUG
    ext('a/b/..')  = '.'       (splitext: '')   BUG

ROOT CAUSE: the scan never identified the leading dot-run boundary, so a '.'
sitting inside that prefix (everything for ".."/"..."/"..ext") was mistaken for
an extension separator. path_stem inherits the defect transitively
(stem("..ext") = "..e", want "..ext").

CROSS-CHECK (g5): differential vs posixpath.splitext(basename) over 58 inputs —
the UNFIXED body diverged on 10 leading-dot cases (.., ..ext, ..., ....y, a/..,
/.., a/b/.., a/b/../.., ..//.., a/b/../..); the FIXED body matches the reference
on all 58 and regresses NO ordinary case (foo.txt→.txt, a/b.tar.gz→.gz,
archive.TAR→.TAR, a.→., .bashrc→"", .config→"" all unchanged).

FIX (minimal, behavior-correct — provably the bug, matches posixpath.splitext):
skip the leading run of dots first, then only treat a '.' AFTER that run as the
extension separator.

    let mut lead = 0
    while lead < n { if base[lead] != '.' { break } lead = lead + 1 }   // ADDED
    let mut i = n - 1
    while i > lead {                                                      // was i > 0
        if base[i] == '.' { return base.substring(i, n) }
        i = i - 1
    }
    return ""
