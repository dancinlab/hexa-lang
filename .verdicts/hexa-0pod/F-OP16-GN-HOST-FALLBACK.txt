THE GAP (OP-15 #2994 finding, REPRODUCED verbatim)
────────────────────────────────────────────────────────────────────────────
A `hexa run` harness that `use`s stdlib/flame/gn_lib FAILS TO LINK off a no-CUDA
build:
    Undefined symbols for architecture arm64:
      "_forge_dispatch_groupnorm_gelu", referenced from:
          _nn_gn_gelu_fused_off in hexa_run-*.o
    ld: symbol(s) not found for architecture arm64
    clang: error: linker command failed with exit code 1

gn_lib's nn_gn_gelu_fused_off (stdlib/flame/gn_lib.hexa:321) calls
forge_dispatch_groupnorm_gelu under an env gate (HEXA_FUSE_GN_GELU +
CLM_PROD_DEVRESIDENT + goff==0 && boff==0). The CALL SITE is env-gated so at
RUNTIME the host loop runs anyway — BUT codegen (self/codegen.hexa:7838 maps
forge_dispatch_groupnorm_gelu → the bare symbol; the deployed hexat emits the
bare `forge_dispatch_groupnorm_gelu`) ALWAYS emits the symbol REFERENCE, and the
bare `forge_dispatch_groupnorm_gelu` C body has NO host definition off-CUDA → the
LINK fails before any code runs. The whole L3 fused-dispatch family (gelu2 /
groupnorm_gelu / moe_block2) is host-undefined off-CUDA: the GPU build supplies
them via the hand-written fusion_dispatch.c glue (launcher + `#ifdef HEXA_CUDA`,
see .verdicts/hexa-fusion/p1b-aprime2-build/fusion_dispatch.c), which is ABSENT
off-CUDA. So the fused-valley GN+GELU path was not locally `hexa run`-testable on
CPU — the 0-GPU determinism-test blind spot OP-15 named.

(this test `use`s gn_lib) → the exact undefined-symbol link error above.

THE FIX — HOST BODY LOCATION + IDIOM
────────────────────────────────────────────────────────────────────────────
LOCATION: self/runtime.c (the forge host-runtime TU), as an `#ifndef HEXA_CUDA`
definition of the BARE symbol `forge_dispatch_groupnorm_gelu`, mirroring the
existing host-fallback idiom in the SAME TU:
  - the bare-wrapper seam `forge_dispatch_matmul` (RFC 050 L1) — bare symbol the
    deployed hexat emits, paired with the runtime.h prototype (already present:
    self/runtime.h:1238);
  - the host CPU-oracle twin `hexa_forge_dispatch_matmul_batched` — `#ifdef
    HEXA_CUDA` launcher, else a byte-eq host loop reading _hx_farr_table[id].buf;
  - the FP_CONTRACT OFF byte-eq blocks (the ag_tape host oracles) — REQUIRED here
    (see "byte-eq cure" below).

`#ifndef HEXA_CUDA` is deliberate: under HEXA_CUDA the symbol is provided by
fusion_dispatch.c, so guarding the host body off-CUDA avoids a duplicate symbol
AND leaves the GPU dispatch path byte-identical to today (GPU path UNCHANGED).

SEMANTICS: identical to gn_lib's own host loop and to the OP-9 (#2987) unfused
reference that was already PROVEN bit-exactly equal (max|Δ|=0) to the fused
device kernel:
  - two-pass mean/var, t-outer / c-inner reduction order (no tree re-assoc);
  - eps = 1e-5 placement var+eps; inv = 1/_op16_gn_sqrt(var+eps);
  - _op16_gn_sqrt = the 40-iteration Newton recurrence g=0.5*(g+x/g), seed g0=x
    (byte-identical to gn_lib _gn_sqrt / nn_lib _nn_sqrt);
  - affine y = gamma[ch]*xhat + beta[ch]; xhat = (x-mu)*inv;
  - GELU a = y * 0.5*(1 + erf(y * 0.70710678118654752440)) — erf is libm (the
    same hexa_math_erf the hexa `erf` builtin lowers to);
  - writes y_out (pre-GELU GN, bwd cache), a_out (GELU), mean_out, inv_out,
    xhat_out via the FP64 farr buffers; returns hexa_int(0) ok, hexa_int(-1) on
    bad ids/dims (caller falls through to its own host loop — also byte-eq).

BYTE-EQ CURE (the one non-obvious finding): with a naïve host body, max|Δ| was a
constant ~3.55e-15 (1-2 ULP), NOT 0 — clang -O2 FMA-CONTRACTS the affine
`gamma*xhat + beta` into one fma, but hexa codegen emits NON-contracted
sequential rounding. Wrapping the host body in
    #pragma STDC FP_CONTRACT OFF  …  #pragma STDC FP_CONTRACT DEFAULT
(the exact proven recipe the ag_tape host oracles in the same TU already use)
drops max|Δ| to EXACTLY 0. Without it, the fused dispatch is correct to ~1 ULP
but NOT byte-eq.

VERBATIM HOST BODY (apply at self/runtime.c, after the FFN bare-wrapper region /
the matmul_batched host oracle — anywhere _hx_farr_table is in scope):

  #ifndef HEXA_CUDA
  #pragma STDC FP_CONTRACT OFF
  static double _op16_gn_sqrt(double x) {
      if (x <= 0.0) return 0.0;
      double g = x;
      for (int i = 0; i < 40; i++) g = 0.5 * (g + x / g);
      return g;
  }
  HexaVal forge_dispatch_groupnorm_gelu(HexaVal x_v, HexaVal gamma_v, HexaVal beta_v,
                                        HexaVal y_v, HexaVal a_v, HexaVal mean_v,
                                        HexaVal inv_v, HexaVal xhat_v,
                                        HexaVal t_v, HexaVal c_v, HexaVal g_v) {
      int64_t x  = hexa_as_num(x_v),  gm = hexa_as_num(gamma_v), bt = hexa_as_num(beta_v);
      int64_t y  = hexa_as_num(y_v),  a  = hexa_as_num(a_v),     mn = hexa_as_num(mean_v);
      int64_t iv = hexa_as_num(inv_v), xh = hexa_as_num(xhat_v);
      int64_t T  = hexa_as_num(t_v),  C  = hexa_as_num(c_v),     G  = hexa_as_num(g_v);
      if (T <= 0 || C <= 0 || G <= 0 || (C % G) != 0)         return hexa_int(-1);
      if (x < 0 || gm < 0 || bt < 0 || y < 0 || a < 0)        return hexa_int(-1);
      if (mn < 0 || iv < 0 || xh < 0)                         return hexa_int(-1);
      if (x  >= _hx_farr_count || gm >= _hx_farr_count || bt >= _hx_farr_count ||
          y  >= _hx_farr_count || a  >= _hx_farr_count || mn >= _hx_farr_count ||
          iv >= _hx_farr_count || xh >= _hx_farr_count)        return hexa_int(-1);
      int64_t cg = C / G;
      int64_t n  = T * C;
      if (_hx_farr_table[x].len  < n || _hx_farr_table[y].len  < n ||
          _hx_farr_table[a].len  < n || _hx_farr_table[xh].len < n ||
          _hx_farr_table[gm].len < C || _hx_farr_table[bt].len < C ||
          _hx_farr_table[mn].len < G || _hx_farr_table[iv].len < G)
          return hexa_int(-1);
      double* X  = _hx_farr_table[x].buf;
      double* GM = _hx_farr_table[gm].buf;
      double* BT = _hx_farr_table[bt].buf;
      double* Y  = _hx_farr_table[y].buf;
      double* A  = _hx_farr_table[a].buf;
      double* MN = _hx_farr_table[mn].buf;
      double* IV = _hx_farr_table[iv].buf;
      double* XH = _hx_farr_table[xh].buf;
      if (!X || !GM || !BT || !Y || !A || !MN || !IV || !XH)   return hexa_int(-1);
      const double eps        = 0.00001;
      const double inv_sqrt2  = 0.70710678118654752440;
      double m = (double)(cg * T);
      for (int64_t g = 0; g < G; g++) {
          int64_t c0 = g * cg;
          double sum = 0.0;                       /* pass 1: group mean */
          for (int64_t t = 0; t < T; t++)
              for (int64_t c = 0; c < cg; c++)
                  sum = sum + X[t * C + (c0 + c)];
          double mu = sum / m;
          double vs = 0.0;                        /* pass 2: group var */
          for (int64_t t = 0; t < T; t++)
              for (int64_t c = 0; c < cg; c++) {
                  double d = X[t * C + (c0 + c)] - mu;
                  vs = vs + d * d;
              }
          double var = vs / m;
          double inv = 1.0 / _op16_gn_sqrt(var + eps);
          MN[g] = mu;
          IV[g] = inv;
          for (int64_t t = 0; t < T; t++)         /* affine + GELU, single sweep */
              for (int64_t c = 0; c < cg; c++) {
                  int64_t ch  = c0 + c;
                  int64_t idx = t * C + ch;
                  double xhat = (X[idx] - mu) * inv;
                  XH[idx] = xhat;
                  double yv = GM[ch] * xhat + BT[ch];
                  Y[idx] = yv;
                  A[idx] = yv * (0.5 * (1.0 + erf(yv * inv_sqrt2)));
              }
      }
      return hexa_int(0);
  }
  #pragma STDC FP_CONTRACT DEFAULT
  #endif
