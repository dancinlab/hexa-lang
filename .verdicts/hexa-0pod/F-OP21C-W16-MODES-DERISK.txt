THE HARNESS (tool/wgmma/w16_modes_cpu_check.cpp — clang++ -std=c++17, ZERO GPU/CUDA/PTX)
---------------------------------------------------------------------------------------
Ports the pure-arithmetic SSOT VERBATIM from w10_lib.h + w16.cu (gmma_phys 8x4 INTER core,
tf() TF32 round, the composed_A / composed_B read laws) AND models the device epilogue
register->global scatter VERBATIM from gemm_w16 L395-403 (= gemm_w10 L184-190). Asserts 6
element-for-element / bit-exact CPU checks (the additional MODEs' GPU-free reference logic):

  C1a  EPILOGUE SCATTER = BIJECTIVE FULL COVER of the 128x128 output tile. Sweeps both
       warpgroups (band 0/1), all 128 lanes, all 32 accumulators, both d0/d1 — every output
       (row,col) written EXACTLY ONCE (no double-write, no gap). If the scatter were wrong the
       MODE-4 device result is wrong REGARDLESS of the GEMM math, so this gates MODE 4 just as
       much as the arithmetic does. (rb=w*16+(l>>2), cb=(l&3)*2, d0->N0..63, d1->N64..127.)
  C1b  MODE-4 FULL-TILE (128x128) REFERENCE GEMM = TF32-round-inputs + fp32-FMA, accumulated
       in the KERNEL's K-order (TKSW=32 slabs, TK=8 inner sub-steps), reproduces a straight
       increasing-k TF32-round + fp32-FMA GEMM bit-for-bit over the WHOLE tile (K=3*TKSW=96 so
       the NST=3 ring turns). Confirms MODE 4's gate (rel_rms vs cuBLAS-TF32) compares the
       device output against the RIGHT reference at FULL-TILE scale (extends OP-21B T6's 8x8).
  C2   B PER-SLAB READ recovers global B bit-exact across ALL NST=3 slabs AND all 4 N-atoms
       (NATOM=TN/TKSW=4). A distinct B tile per slab (per-slab RNG seed) catches slab-cross
       aliasing. composed_B(k,n) lands then reads back -> must recover B[k][n] for every
       (slab,k,n). (extends OP-21B T5's single slab / 2 atoms.)
  C3   gemm_w16b BAND DECODE == gemm_w16 OPERANDS. gemm_w16b software-decodes Asw -> As0/As1
       (composed_A -> gmma_phys repack, w16.cu L458-463) and Bsw -> B0/B1 (composed_B ->
       gmma_phys repack, L464-469) into the gmma band, then wgmma reads the band. Reading the
       band back through gmma_phys reconstructs the SAME logical operands gemm_w16 reads in
       place from global — the repack is a pure value-preserving reshuffle (A=4096/4096,
       B=4096/4096 bit-exact).
  C3b  closes C3: the per-slab 128x128 GEMM computed FROM the w16b band == the per-slab GEMM
       gemm_w16 computes from global, element-for-element (16384/16384) — both fp32-FMA over
       tf32 inputs in the same increasing-k order. Different scheduling, IDENTICAL math.
  C4   DESCRIPTOR STRIDE byte arithmetic self-consistent ACROSS the NST=3 stages: (i) ring
       slot bases st*SWBUF (SWBUF=8192 floats) non-overlap + contiguous over the stages; (ii)
       gemm_w16 kk*4-byte START bumps tile one 128B swizzle row per atom [0,32,64,96]B for the
       4 sub-steps; (iii) gemm_w16b (kk>>3)*512*4 bumps tile the 4 gmma sub-tiles
       [0,2048,4096,6144]B (512-float/2048B each); (iv) MODE-1/MODE-4 defaults (lbo=16,
       sbo=1024) match the 256-float (1024B) atom.
