THE 6TH DETERMINISM SURFACE
  The campaign locked: step math (F-OP15), input pipeline (F-OP28), 4 archs
  (F-OP29 etc.), schedule (F-OP33), cross-platform transcendentals (F-OP19/19b).
  A machine-independent run is only USEFUL if you can STOP it, serialize the
  state (W, AdamW m/v, step t), restore, and RESUME with the trajectory
  byte-identical to an uninterrupted run. Serialization is a classic determinism
  hole: (a) float→TEXT loses bits; (b) binary endianness/layout; (c) missing
  optimizer state (m,v,t) restarts bias-correction; (d) field/iteration order.

AUDIT (what existed in stdlib/flame — the honest finding)
  · clm_ckpt.hexa (.clm v0.1/v0.2, PR2 of CLM_PROD_TRAINER_PLAN): an int4-QAT
    INFERENCE export — weights as int4 codes + fp32 scales; the v0.2 "CLMX" ext
    trailer (embed/GN affine/biases) is fp32. Round-trip is exact FOR WHAT IT
    STORES, but as a TRAINING checkpoint it has BOTH classic holes:
      hole (a'): fp64 training state stored at fp32 → 29 mantissa bits lost →
                 restore ≠ original → resumed trajectory diverges from k+1;
      hole (c) : NO AdamW m, NO v, NO step t → a resume restarts bias-correction
                 at t=1 → diverges even with exact weights.
  · flame_load_pt.hexa / pt_loader.hexa: PyTorch IMPORT readers, not save paths.
  · train_lib.hexa / optim_lib.hexa / nn_lib.hexa: no save/load/serialize path.
  → VERDICT: NO training checkpoint existed in stdlib. Not a "bug found in a
    checkpoint path" — the path was MISSING (and the nearest thing, the .clm
    export, would silently diverge if abused as one — both holes are now
    DEMONSTRATED in-band, below). REAL-AND-CLOSED.

THE CLOSE — stdlib/flame/ckpt_lib.hexa ("FCK\x01" v1)
  Minimal deterministic training checkpoint:
    [MAGIC 'F','C','K',0x01][t_step u32-le][n_params u32-le]
    per param, pinned canonical order: [len u32-le][len×f64-le W][len×f64-le m]
                                       [len×f64-le v]
  · BINARY fp64-LE via f64_to_bytes_le / bytes_to_f64_le — IEEE-754 bit-pattern
    reinterpret, NO text round-trip, NO narrowing.
  · LITTLE-ENDIAN PINNED — bytes are the contract, not host layout.
  · COMPLETE state: every W + m + v + the applied step t (resume = t+1).
  · FIXED field order — the byte stream is a pure function of (state, order).
