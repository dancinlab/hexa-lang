🔴 REAL SHIPPING BUG FOUND + FIXED — stdlib/alloc/argparse.hexa ap_parse
═══════════════════════════════════════════════════════════════════════

METHOD: DIFFERENTIAL — a verbatim Python port of the UNFIXED ap_parse body
vs Python's stdlib `argparse` (the module header's stated reference:
"Python-argparse subset"), over a boundary sweep (attached-value,
separated-value, flag-before/after-positional, value-at-EOL, extra-pos).

BUG: the `--long=value` / `-o=value` ATTACHED-VALUE form was never
recognised. `_match_value` only does an EXACT `tok == v["long"]` compare,
so `--out=foo.txt` matched NOTHING and fell through to POSITIONAL capture.
One attached-value token then derailed the entire positional assignment:

  VERBATIM (Python port of unfixed body vs argparse, parser =
   -v/--verbose flag, -o/--out value default "def.txt", positional file):

    ARGV ['--out=foo.txt', 'x']
      HEXA out: def.txt | verbose: False | file: --out=foo.txt | extras: ['x']
      PY   out: foo.txt  | verbose: False | file: x

  → out kept its DEFAULT (user's value silently dropped),
    the `--out=foo.txt` token CORRUPTED the positional `file`,
    and the real positional `x` overflowed into `_extras`.

ROOT CAUSE: the value-match path never split a token on '=' before
matching — a structural gap in the documented Python-argparse subset, not
a one-off (every `--key=value` invocation is mis-parsed).

FIX (minimal, provably-correct — matches Python argparse): before falling
through to positional, find the first '=' in the token (_eq_index), match
the key part as a value option, and assign the post-'=' tail. Split on the
FIRST '=' only (so `--out=a=b=c` → value "a=b=c"). 0 deletions; +1 helper
(_eq_index) + one branch in ap_parse. @version 0.1.0 → 0.2.0.

CROSS-CHECK (g5): the FIXED Python port vs Python argparse over all
well-defined cases → 0 mismatch:
    OK ['--out=foo.txt','x']      -> ('foo.txt', False, 'x')
    OK ['-o','foo.txt','x']       -> ('foo.txt', False, 'x')   (separated preserved)
    OK ['-o=foo.txt','x']         -> ('foo.txt', False, 'x')   (short attached)
    OK ['--out=a=b=c','x']        -> ('a=b=c',   False, 'x')   (first '=' only)
    OK ['--out=','x']             -> ('',        False, 'x')   (empty attached)
    OK ['--verbose','x']          -> ('def.txt', True,  'x')
