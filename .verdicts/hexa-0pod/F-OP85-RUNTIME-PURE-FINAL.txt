4. 🔴 BUG FOUND (in the OP-85 TEST, not a shipping module)
─────────────────────────────────────────────────────────────────────
First heap_pure_test draft used a hand-rolled insertion-sort as the
"sorted" reference. On the local stale build its `a[q+1] = a[q]` index-
assignment shift produced GARBAGE (e.g. sorted([5,3,8,1,9,2,7,4,6,0]) →
[0,6,7,9,8,5,8,8,8,9]) — the exact array-index-assignment fragility the
heap MODULE deliberately avoids via copy-on-write _h_set_at. The heap
module itself was CORRECT all along (its drains produced [0..9] and the
dup case [1,1,1,2,2,3,3,4,4,4]). FIX: replaced the buggy reference with
LITERAL golden sorted arrays (the most authoritative ref anyway). No
shipping module touched. (This is a reference-side defect, surfaced and
closed before landing — no 🔴 in any audited *_pure module.)
