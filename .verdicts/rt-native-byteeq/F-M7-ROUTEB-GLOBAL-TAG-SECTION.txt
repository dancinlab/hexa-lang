================================================================================
1. ROOT CAUSE (c2 — gdb + objdump on aiden, decisive, NOT a guess)
================================================================================
measure-6 framed the wall as "x86_64 global-tag persistence codegen 결함 — g+8
write 시드에 0개". That was HALF the story. RUNNING the genuine repro (a hexat
built with HEXA_RT_ALLOC_NATIVE=1, the heaviest real hexa program) under gdb
isolated TWO distinct asymmetries vs arm64:

(1) MODULE-GLOBAL TAG NEVER PERSISTED (the named wall, real):
    x86_64 global WRITE stored only the payload to word0 ([rip+g<id>]); the tag
    went to a per-FUNCTION frame tag-slot. x86_64 global READ recovered the tag
    from the READING function's OWN frame tag-slot. So a global written in fn A
    and read in fn B → B's frame tag-slot was never populated → tag = TAG_INT(0).
    arm64 has NO such gap: ldp/stp move BOTH 16-byte words of the `g<id>` .data
    slot (the slot IS the cross-function SSOT).

(2) THE g<id> SLOTS LANDED IN .text (read-only) — THE ACTUAL RC=139 (the deeper
    wall measure-6 could not see because it never RAN the heavy repro):
    gdb faulting instruction (the genuine RC=139):
        => mov %r13, 0x...(%rip)   # <g2>     ← global PAYLOAD write, SIGSEGV
    objdump -t on the assembled seed:
        g0..g3   l   .text   ← READ-ONLY section
    __env_extend's `__arena_env_lo = base` (a write to [rip+g2]) hit a read-only
    .text page → SIGSEGV. Mechanism: the x86_64 emit places `main:` BEFORE the
    `.section .data` + `g<id>: .quad 0 .quad 0` slots. The regen script's
    main-strip awk set `inmain=1` at `main:` and skipped lines until a `symbol:`
    or `.globl` — but `.section .data` is NEITHER, so the directive was SWALLOWED;
    `g0:` (a symbol:) survived but inherited the prior `.text` section. arm64
    Mach-O is unaffected (its global pool emits into __DATA,__data separately).
    (Compounding: aiden's awk is mawk 1.3.4, which does NOT support `\b` — the
    first section-stop patch used `\b` and silently never matched.)

2. THE FIX (c1, three commits — ADD-only codegen + regen-script + regen seed)
================================================================================
  · compiler/codegen/x86_64_linux.hexa (ADD-only, byteeq-inert):
    - _x86_emit_dst_writeback global path (arena_id==-999) now ALSO persists the

  · self/native/alloc_syscall_x86_64.s: regenerated (frozen seed). New seed:
