SHIM DESIGN — tool/hx-selfhost-cli
----------------------------------------------------------------
A tiny (~95-line) bash launcher that replaces the bare `exec gen3` (hx-selfhost).
Routes by EXPLICIT surface detection, NEVER by gen3's exit code (gen3 returns
rc 0 even on subcommands it cannot parse — see PROBE below):

  ROUTE  -> gen3 (self-hosted):  any invocation carrying `--emit=<x>` — the exact
           bare-compiler surface tool/selfhost_parity_gate.sh validates. The shim
           injects the driver-placeholder argv1 and an empty HEXA_ATLAS_EMBED:
               exec gen3 _drv.hexa <user args...>   (SOURCE.hexa = last positional)
  DELEGATE -> shipped dispatch:  EVERYTHING else — named subcommands
           (build/run/verify/atlas/...), --version, --help, any non-emit call.
           Target = newest hexa.real.pre-selfhost.<ts> backup (the shipped
           `hexa 0.1.0-dispatch`). Symlink-loop guard: refuses to recurse into
           a hexa.real that is itself a symlink with no backup present.

  Safety > coverage: build/run are DELEGATED (NOT mapped onto gen3). gen3's
  link path needs specific clang+hexa_ld orchestration and the shipped `build`
  does extra libsodium/openssl linking the shim cannot safely replicate.
  When unsure -> DELEGATE, so the full CLI + every hook keeps working verbatim.

GEN3-BACKED SURFACE FRACTION : the compile surface only (`SOURCE.hexa --emit=*`).
  Everything operators/hooks invoke by name (run/verify/atlas/build/--version)
  is delegated to the shipped dispatch binary -> 100% CLI compatibility retained.

promote_selfhost.sh : tier1 now also installs the CLI shim; tier2 symlinks
  hexa.real -> hx-selfhost-cli (REFUSED if the shim is absent — never flips to
  bare gen3). --status gained a `cli-shim` line. --revert unchanged.
