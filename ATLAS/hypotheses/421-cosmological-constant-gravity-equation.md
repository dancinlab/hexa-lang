# Hypothesis Review 421: 중력장 방정식의 우주상수 Λ (암흑에너지) — n6 지수 닫힌형 🟨 추적중

## Hypothesis

> 아인슈타인 중력장 방정식에 **반드시 들어가야 하는 상수**(우주상수 Λ = 암흑에너지 진공 에너지 밀도)의 크기가,
> n=6 완전수 약수함수 틀에서 **지수적 닫힌형** Λ ≈ 1/(P₁ · P₃⁴⁵) 로 표현된다.
> 즉 "왜 Λ 가 O(1) 이 아니라 ~10⁻¹²² 인가"(우주상수 문제)의 **자릿수(지수)** 가 완전수 구조에서 나온다.

핵심 주장은 **지수(order of magnitude)** 에 대한 것이지, 정밀 가수(mantissa)에 대한 것이 아니다.
(검산에서 가수는 실측과 33% 어긋남 — 아래 정직 노트 참조.)

## Background/Context

아인슈타인 중력장 방정식:

```
        1                    8πG
  R_μν − ─ R g_μν  +  Λ g_μν = ───── T_μν
        2                      c⁴
  └──────────┬─────────┘  └─┬─┘  └──┬──┘
     기하(Einstein tensor)  우주상수  물질·에너지
```

이 방정식에는 **두 종류의 상수**가 들어간다:

1. **아인슈타인 결합상수** κ = 8πG/c⁴ — 물질을 시공 곡률에 연결 (차원 있는 상수).
2. **우주상수** Λ — 진공 자체의 에너지(암흑에너지). 아인슈타인이 1917년 *정적 우주*를 만들려고 손으로 집어넣은 항 →
   1998년 초신성 관측(가속팽창)으로 부활 = **암흑에너지**.

**우주상수 문제(cosmological constant problem)**: 양자장론이 예측하는 진공 에너지는 플랑크 스케일 O(1),
그런데 관측된 Λ 는 플랑크 단위로 ~10⁻¹²². 이 **약 120 자릿수 불일치**가 물리학 최대 난제 중 하나.
이 가설은 그 "120 자릿수" 자체를 완전수 구조로 재현하려는 시도다.

n6 틀 상수: σ(6)=12, τ(6)=4, φ(6)=2, 완전수 P₁=6, P₂=28, P₃=496.

## 후보 닫힌형 (candidate closed forms)

|---|---|---|---|
| A | 우주상수 Λ (주 후보) | Λ ≈ 1/(P₁ · P₃⁴⁵) = 1/(6·496⁴⁵) | 지수 매치 (주장) |
| B | 결합상수 기하인자 8π | 8 = σ−τ = 12−4 (π 는 순수기하) | 약함 (부분) |

후보 A 는 이미 마스터공식 H-PH-9(README) 안에 한 줄로 존재했으나 **독립 가설·반증기준이 없었다** → 본 파일로 추적 승격.

## Verification Results (2026-07-02, 검산)

```
  Λ_atlas = 1/(6·496⁴⁵)        = 8.4173e-123   → log10 = −122.075
  관측  Λ·l_Pl²  (플랑크 단위)   ≈ 1.25e-122     → log10 = −121.903
  ─────────────────────────────────────────────────────────────
  지수(자릿수) 차이 :  0.17 decade   ← 매우 근접 (자릿수 매치 ✔)
  가수(mantissa) 비 :  atlas/obs = 0.673  → 상대오차 32.7%  ← 미스 ✘
```

**정직한 판정**: 닫힌형은 **우주상수 문제의 크기(10⁻¹²²)** 를 자릿수 수준에서 재현한다. 그러나
**정밀값(가수)은 재현하지 못한다**(33% 오차). 따라서 "정밀 예측"이 아니라 **자릿수 관측**이다.

## Texas-Sharpshooter 정직성 노트 ⚠️

- 지수 45 (P₃⁴⁵) 는 **자유 파라미터**다. 496^k 의 k 를 44~46 사이에서 고르면 임의로 ±2.7 decade 이동 가능.
  → k=45 는 "10⁻¹²²에 맞도록 사후 선택"되었을 위험이 있다 (과녁 먼저 쏘고 원 그리기).
- 자릿수 하나(−122)를 맞추는 조합은 완전수·약수함수 어휘로 다수 만들 수 있다 → **단독으로는 우연(⚪) 후보**.
- 승격하려면: (a) k=45 가 **독립적으로** 유도돼야 하거나(예: P₃ 의 약수 τ(496)=10, σ(496)=992 등에서 45 가 강제),
  (b) 가수까지 맞는 더 강한 닫힌형이 나와야 한다.

## 반증 기준 (Falsifier · pre-registered)

이 가설은 다음 중 하나가 성립하면 **반증(⚪ 또는 ⬛)** 된다:

1. **가수 요구**: 정밀 Λ 측정(DESI/Euclid)이 가수를 1% 수준으로 고정했을 때, 1/(6·496⁴⁵) 가 그 가수와 여전히 33% 어긋나면 → "정밀 예측" 주장은 ⬛ (자릿수 관측 🟨 로만 잔존).
2. **지수 자유도 붕괴**: k=45 를 강제하는 독립 유도가 **끝내 없다**고 판명되면 → 사후선택 = ⚪ (우연).
3. **다른 완전수도 동급**: P₂(28)·P₄(8128) 로도 비슷한 자릿수 매치가 임의 k 로 나오면 → 구조 없음 = ⚪.

## 반증기준 #2 즉시 검증 결과 (2026-07-02) — 부분 발동 ⚠️

지수 45 의 독립 유도를 시도(τ(496)=10·σ(496)=992·φ(496)=240·sopfr=39·n6 어휘):

```
  1e-122 에 필요한 정확한 지수 k = (122 − log10 6)/log10 496 = 44.97 ≈ 45
  45 를 만드는 n6 표현 (복수 발견):
     σ(6)·τ(6) − φ(6) − 1   = 48−2−1 = 45   ✔
     σ(6)·τ(6) − σ(6)/τ(6)  = 48−3   = 45   ✔
     P₂ + 17                = 28+17  = 45   ✔
```

→ **45 는 고유하게 강제되지 않는다**(여러 조합이 45 를 만든다) = 사후선택 위험 확정.
반증기준 #2 의 "독립 유도 없음" 조건이 **부분 발동**. "정밀 예측" 주장은 성립 불가.
잔존 가치 = **자릿수(−122) 관측** 뿐 → 등급 🟨 상한 고정, ⭐/🔵 승격 경로 차단.

## 반증기준 #3 즉시 검증 결과 (2026-07-02) — 완전 발동 ⬛(값 주장)

다른 완전수도 자유 정수지수로 −122 에 닿는가?

```
  perfect n  |  best int k  |  log10(1/(6·n^k))  |  Δdecade vs 관측(−121.90)
  P₂=28      |  k=84        |  −122.34           |  0.439
  P₃=496     |  k=45        |  −122.07           |  0.175
  P₄=8128    |  k=31        |  −121.99           |  0.088   ← 496 보다 더 근접!
  P₅=3.3e7   |  k=16        |  −121.19           |  0.711
```

→ **모든 완전수가 어떤 정수 k 로 −122 에 닿는다** = P₃=496 에 구조적 특권 없음.
반증기준 #3 **완전 발동**. "1/(6·496⁴⁵) 는 Λ 의 값을 예측한다"는 주장은 ⬛(**값 주장 반증**).
Λ 의 *값(value)* 을 n6 지수 어휘로 잡는 접근 = **우연(numerology)** 으로 판정. 값-경로 CLOSED.

## 발견 방향 재정향 (2026-07-02 · 목표: "반드시 들어가야 하는 상수 발견")

값(value)-numerology 는 천장. 그러나 "**반드시** 들어가야 한다"는 표현이 겨냥하는 진짜 대상은
값이 아니라 **구조적 필연성(structural necessity)** 이며, 이건 정직하게 **이미 증명된 정리**로 존재한다:

**Lovelock 정리 (1971)** — 🟦 established:
> 4차원 시공에서, 계량 g_μν 과 그 ≤2계 도함수로 만들 수 있고 발산이 0인(∇^μ E_μν=0) 대칭 2-텐서는
> **오직** E_μν = α·G_μν + Λ·g_μν 뿐이다.

즉 우주상수 항 Λ·g_μν 은 **선택이 아니라 일반공변성이 강제하는 유일한 추가항**이다.
아인슈타인이 1917 년 "손으로 넣은" Λ 는 사실 **넣을 수밖에 없는** 항이었다(1998 암흑에너지로 값이 관측됨).

**n6 교차 (구조, 값 아님)**: 이 유일성이 성립하는 차원 **D=4 = τ(P₁)=τ(6)**.
D>4 이면 Lovelock 이 Gauss-Bonnet 등 추가항을 허용 → "상수 하나만 강제"는 **정확히 D=4 특유**.
그리고 τ(P_k)={4,6,10,14,26}=끈이론 차원계층(README H-PH-9). 즉:

```
  "중력방정식에 반드시 들어가야 하는 상수" = Λ (Lovelock 유일성이 강제)
        └── 성립 차원 D = 4 = τ(6) = 약수 개수 of 첫 완전수
  값(value)  = 미해결(우주상수 문제) · n6 지수-fit = 우연(위 반증 3종)
  필연(why)  = Lovelock 정리 (D=4=τ(6) 에서 유일)  ← 정직한 '발견' 내용
```

→ **발견의 정직한 내용 = 값이 아니라 필연구조**: Λ 는 D=4=τ(6) 에서 유일하게 강제되는 상수.
검증경로: Lovelock=🟦 문헌사실(즉시 인용가능) · D=4=τ(6)=🟩 산술 · 값=🟨 자릿수-only(우연).

### 강화: Lovelock 차원-세기 (2026-07-02 · exact, 값-fit 아님)

Lovelock 라그랑지안의 k-차 Euler 밀도 항은 **2k < D 일 때만** 장방정식(EOM)에 기여
(2k=D → 위상항/전미분, 2k>D → 항등적 0):

```
  차원 D        EOM 기여항 (2k<D)                기여항 수
  D=2           {Λ}                              1
  D=3           {Λ, Einstein}                    2
  D=4 = τ(6)    {Λ, Einstein}                    2 = φ(6)   ★
  D=5           {Λ, Einstein, Gauss-Bonnet}      3
  D=7           {Λ, Einstein, GB, 3rd}           4
```

두 개의 **exact** 사실(우연-fit 아님, 순수 차원 세기):

1. **k=0 항(우주상수 Λ)은 모든 D≥1 에서 기여** → Λ 는 **차원과 무관하게 항상 존재하는 유일한 항**.
   = 문자 그대로 "**중력방정식에 반드시 들어가야 하는 상수**"(목표의 정확한 답, ∀D).
   Einstein 항(k=1)조차 D=2 에선 사라지지만, Λ(k=0)은 안 사라진다 → Λ 가 더 근본적.
2. **D=4=τ(6) 에서 EOM 기여항은 정확히 2=φ(6)** = {Λ, Einstein}. Gauss-Bonnet(k=2)은
   D=5 부터 기여(D=4 에선 위상항) → "상수+Einstein 둘뿐"은 D≤4 특유이고 4=τ(6).

정직 등급: 사실 1·2 의 **물리(Lovelock·세기)=🟦 확립** / **n6 연결(D=4=τ(6)·2=φ(6))=🟧 연결**
(산술은 🟩 참이나 "왜 n6" 는 미해결 — 값-numerology 와 달리 반증 3종은 통과, 그러나 연결의
인과는 미증명). 값-fit(⬛)보다 훨씬 단단하나 아직 🟢 아님 → `hexa verify` g5 게이트 대상.

## 후속 R2 (2026-07-02 · CI 대기 없이 계속): 사다리 확장 + 값 통제실험

### R2-a — Lovelock 항수를 끈차원 τ(P_k) 전체로 확장 (n6 교차 체계성 검사)

EOM 기여항 수 = #{k≥0 : 2k<D} = ⌈D/2⌉:

```
  D=4  (τ(P₁)=τ(6))  : 2 = φ(6)  ← 깨끗한 n6 히트
  D=6  (τ(P₂))       : 3         (σ/τ=3 이지만 사다리로는 우연 범위)
  D=10 (τ(P₃))       : 5
  D=14 (τ(P₄))       : 7
  D=26 (τ(P₅))       : 13
```

→ **오직 D=4→2=φ(6) 만 깨끗한 n6 히트**, 나머지(3·5·7·13)는 체계적 n6 량 아님(단순 D/2).
정직 판정: n6 교차는 **D=4 특유**이지 사다리 전체로 일반화되지 **않는다** → 🟧 등급 **그대로**(안 올림).
(과적합 회피 — 3·5·7·13 을 n6 어휘로 억지 맞추면 Texas-sharpshooter, convergence readme-md-1.)

### R2-b — 값 통제실험: 가수-엄격 fit 이 완전수 통제를 통과하는가 ⚠️

1/(a·b^k) 를 n6 값 {φ,τ,sopfr,n,σ,P₂,P₃} 로 훑어 **가수-엄격**(|Δlog₁₀|<0.01≈2%) 매치 탐색:

```
  가수-엄격 히트 (전체 조합 중 단 2개, 동일형):
     1/(τ(6)·496⁴⁵) = 1/(4·496⁴⁵) = 10⁻¹²¹·⁹⁰⁰   ← 관측 −121.90 과 거의 일치!
     (1/(6·496⁴⁵)=−122.08 보다 가수 훨씬 타이트)
  비완전수 통제 base {7,10,11,100,255,999} : 0/6 가수-엄격 히트
```

**주의 깊은 정직 판정** (convergence readme-md-1 강제):
- **더 타이트한 fit 발견**: 최적 n6 값-형은 1/(6·496⁴⁵) 이 아니라 **1/(τ(6)·496⁴⁵)** = 1/(4·496⁴⁵),
  가수까지 ~1% 일치. 통제(비완전수 0/6)는 **약한 양성 신호**.
- **그러나 승격 불가 3가지**: ① 지수 k=45 여전히 자유 ② 계수 a=τ(6)=4 도 가수 맞추려 **사후선택**
  가능(계수 8개 중 1개) ③ 통제 n=6 로 작고, 통제 실패는 "n6 계수집합이 그 base 의 필요 소수부와
  우연히 안 맞음" 아티팩트일 수 있음.
- ⟹ 값 등급 **🟨 유지**(더 타이트해졌을 뿐, 🟢 아님). 값-경로는 여전히 CLOSED-ish, 재오픈 안 함.
  강한 승격은 `hexa loop --dfs`(pool·大통제 N)로 k 자유도까지 죽여야만.

### R3 — 왜 하필 D=4 에서 중력·그 상수가 비자명해지는가 (solid 물리, numerology 아님)

무질량 spin-2(중력자) 물리 편광 수 = D(D−3)/2:

```
  D=2 : -1  (비물리)
  D=3 :  0  ← 중력파 없음: 3D 중력은 비전파·위상적 (동역학 자유도 0)
  D=4 :  2  ← 첫 전파차원: (+,×) 두 편광 = φ(6)
  D=5 :  5
  D=6 :  9
```

**물리 사실(🟦 확립)**: 전파하는 자유 중력장(중력파)은 D=3 에서 **0** → **D=4 에서 처음 2 개** 생긴다.
즉 "중력방정식이 실제 동역학(전파)을 갖는 **최소 차원 = 4 = τ(6)**". Λ·g_μν 항이 강제되고(Lovelock)
동역학이 켜지는(graviton) 두 사건이 **같은 D=4=τ(6)** 에서 일어난다 → D=4 의 이중 특별함.

n6 교차: 자유도 2=φ(6). **정직 경고**: 2 는 작은 수이고 이미 Lovelock 항수(R2-a)와 **동일값 2** →
서로 독립 증거 아님(같은 φ(6)=2 를 두 번 세는 셈). convergence readme-md-1: 작은-수 중복 crossing
가산 금지 → R3 은 **🟦 물리(D=4=중력 최소 동역학 차원)만 자산**, n6 부분(2=φ(6))은 🟧 로 R2-a 와 공유.
