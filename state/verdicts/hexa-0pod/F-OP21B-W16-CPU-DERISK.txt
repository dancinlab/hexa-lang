THE ENCODER LOGIC (extracted from w16.cu + w10_lib.h, the SSOT)
--------------------------------------------------------------
TF32 (4B) SWIZZLE_128B canonical atom = 8 rows x 32 floats (128B/row x 8 = 1KB swizzle
period). The 128x32 A tile = 16 vertically-stacked 8-row atoms, ATOM-MAJOR: atom a=m>>3,
within-atom row r=m&7.

  gmma_phys(s,k)   [w10_lib.h L54-56]: GMMA INTER 8x4 core
      strip=s>>3, sr=s&7, kcore=k>>2, kc=k&3; return (strip*2+kcore)*32 + sr*4 + kc
  sw128_measured(r,c) [w10_lib.h L62-64]: 128B-swizzle index inside the 8x32 atom
      g=c>>2, w=c&3, gp = g XOR (r&7); return r*32 + gp*4 + w
  tf(x) [w10_lib.h L469]: TF32 round (round-to-nearest, +0x1000 then &0xFFFFE000)

w16.cu's MODE-0 canonical-decode read law (w16_probe_canon L175):
      sw = a*256 + r*32 + (((k>>2)^(r&7))<<2) + (k&3)
  == the W10 composition  a*256 + sw128_measured(r,k)   (claim verified, T2 below).

B per-slab read law (w10_lib.h gemm_w10 L383-384, == gemm_w16b L466-467):
      c=n>>5, nn=n&31, gp=(nn>>2)^(k&7); sw = c*(TKSW*TKSW) + k*32 + (gp<<2) + (nn&3)

enc_canonical() (w16.cu L142) returns get_enc() — the standard cuTensorMapEncodeTiled
driver entry. D1's "canonical-ness" is NOT a different encoder call; it is (a) the composed
read index in MODE 0 and (b) the descriptor strides (lbo/sbo/boff, swmode=1) in gemm_w16's
mk_sw, which the MODE-1 H100 sweep arbitrates against rel_rms 0.

  T4  gmma_phys is a BIJECTION over the 64x8 wgmma-operand INTER sub-tile (512 slots).
  T5  B per-slab read recovers global B bit-exact (2 side-by-side 32-N atoms, 2048/2048 exact).
  T6  reference GEMM math = TF32-round-inputs + fp32-FMA accumulate (the math gemm_w16
