WHAT IS CHARACTERIZED
--------------------------------------------------------------------------------
The flame CLMConvMoE batched training step (CLM_PROD_BATCH=B in clm_prod.hexa)
concatenates B consecutive DISTINCT length-Tw windows into ONE length-T=B*Tw
buffer and runs the causal-dilated Conv1d over the whole concatenated sequence.
The flame_h100_h200_closeout memory recorded the honest non-bit-exact spot:

  "B>1 window-concat carries a K-1 causal-conv SEAM-only Δ (not bit-identical;
   a true max|Δ|=0 batched step needs a per-window-segmented causal conv)".

This oracle computes the conv BOTH ways on CPU (identical weights/bias/FP dtype):
  (a) WINDOW-CONCAT (flame B>1): one conv over x_concat[T=B*Tw, Cin], every
      previous-window row visible to the receptive field p = t - dil*(K-1-k).
  (b) PER-WINDOW-SEGMENTED reference: each length-Tw window convolved
      INDEPENDENTLY (its own causal zero left-pad), cross-window context ZEROED.
Δ[t] = (a) - (b) per output position.

THE PRECISE PER-POSITION MAP (PROVEN)
--------------------------------------------------------------------------------
· window 0 (b==0)                              : Δ = 0 (no previous window).
· window b>0, local tl ∈ [ (K-1)*dil , Tw )    : INTERIOR, receptive field stays
                                                 inside the window ⇒ Δ = 0
                                                 (bit-exact, max|Δ|=0).
· window b>0, local tl ∈ [ 0 , (K-1)*dil )     : SEAM band — field straddles the
                                                 window start; (a) reads prev-window
                                                 tokens (b) zeros ⇒ Δ = Σ over the
                                                 straddling taps of x_prev·w ≠ 0.

So the SEAM = EXACTLY the first (K-1)*dil output positions of every window AFTER
the first. The INTERIOR is bit-exact (max|Δ|=0). REFINEMENT of the closeout:
  · dil=1  ⇒ band width = K-1  (the closeout's named "K-1 seam" — CONFIRMED).
  · dil>1  ⇒ band width = (K-1)*dil  (the trunk's dilated convs widen the band;
            the closeout said "K-1" — this oracle SHARPENS it to (K-1)*dil).
