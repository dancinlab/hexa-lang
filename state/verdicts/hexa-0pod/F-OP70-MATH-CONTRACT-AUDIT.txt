THE CONTRADICTION — stdlib/core/math/permille.hexa : pm_mul_pm rounding mode
─────────────────────────────────────────────────────────────────────────────
FALSE surface-doc line (permille.hexa:20-21, verbatim, before):
    //   - `pm_mul_pm(a, b)` reduces the implicit ×10^6 product back to
    //     ×10^3 by dividing by 1000 with banker's rounding.

TRUE behavior (permille.hexa:100-101, verbatim):
    pub fn pm_mul_pm(a: PerMille, b: PerMille) -> PerMille {
        return PerMille { pm: _div_round_half_away(a.pm * b.pm, PM_SCALE) }
    }
  _div_round_half_away (permille.hexa:60-70) = round-HALF-AWAY-FROM-ZERO:
        let q = (abs_a + abs_b / 2) / abs_b      // +half then floor on |·|
  This is NOT round-half-to-EVEN ("banker's rounding"). The two modes DIVERGE at
  every half-integer boundary: 0.5 → 1 (half-away) vs 0 (banker's-even);
  2.5 → 3 (half-away) vs 2 (banker's-even); −0.5 → −1 vs 0.

PROOF the BEHAVIOR (not the doc) is SSOT-correct — the pre-existing test already
locks half-away (stdlib/math/permille_test.hexa, before this round):
    T5.mul_pm.0.1×0.005 : pm_mul_pm(pm_of_permille(100), pm_of_permille(5)) == 1
        // 100*5 = 500 pm² → /1000 = 0.5 → half-away = 1  (banker's-even would be 0)
  Half-away is also the construction/div_int mode (permille.hexa:74,97), so
  "banker's" was a stray inconsistent word, not the design. ⇒ DOC is the bug.

FIX (doc + test ONLY — no behavior change, exactly OP-68's wrap_pi call):
  (1) permille.hexa:20-21 doc corrected to state half-away-from-zero
      (`_div_round_half_away`), NOT banker's, with the .5-boundary example.
  (2) permille_test.hexa T5 comment "banker-style half-away" (self-contradictory)
      rewritten to plain half-away.
  (3) NEW T5b rounding-mode lock — cases that FAIL under round-half-to-even and
      thus machine-pin the documented contract:
        T5b.mul_pm.half_away_pos_2.5 : pm_mul_pm(pm_of_permille(50),  pm_of_permille(50)) == 3   // 2.5 → 3 (banker's=2)
        T5b.mul_pm.half_away_neg_0.5 : pm_mul_pm(pm_of_permille(-100),pm_of_permille(5))  == -1  // -0.5 → -1 (banker's=0)
        T5b.mul_pm.half_away_pos_1.5 : pm_mul_pm(pm_of_permille(300), pm_of_permille(5))  == 2   // 1.5 → 2 (tie anchor)
