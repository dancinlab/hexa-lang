==================== §2  THE OP-21A DELTAS IMPLEMENTED (vs W10, cited inline) ==================
All five designed deltas are in the source; each cites the w10_lib.h line it adapts/replaces.
  D1  CANONICAL-ATOM LANDING (Step 1, the FALSIFIABLE core). W15 pinned the descriptor-direct
      failure to our hand-rolled box landing an ATOM-MAJOR a*256-stacked permutation, not the
      canonical CuTe Layout_K_SW128_Atom the wgmma HW de-swizzle addresses. w16 names this
      enc_canonical() and EXPOSES it as the falsifiable gate: MODE 0 (canonical-decode probe)
      and MODE 1 (descriptor-direct probe, swept fields) must hit rel_rms 0 BEFORE any GEMM. The
      canonical-ness is realized as the (lbo,sbo,boff,swmode) the descriptor strides — exactly
      what W15 proved must change — with the box geometry held so the TMA still lands SWIZZLE_128B
      8-row atoms. PRE-REGISTERED FALSIFIER: if MODE 1 floors at ~1.0/1.392 (the W15 wall), D1
      FAILED -> OP-21B.
  D2  DESCRIPTOR-DIRECT wgmma (Step 2, delete the 32KB band). gemm_w16 reads wgmma operands
      DIRECTLY from the swizzled smem via mk_sw(swmode=1) — the As0/As1/B0/B1 gmma decode scratch
      (w10_lib.h L361) is REMOVED. smem/CTA: the W15-measured 96->64KB drop (2 CTA/SM held).
  D3  NST=3 DECODE-FREE RING (Step 3). Only the swizzled tiles ring (w10_lib.h L331 SWBUF), now
      NST-deep (default 3); the 32KB band-removal headroom buys the extra stage at 2 CTA/SM.
  D4  wgmma.wait_group<NST-2> (Step 3). Replaces w10_lib.h L407's wgmma.wait_group 0 (which
      drained EVERY slab -> serialization). w16 commits per slab then waits<1> (=NST-2 @NST=3)
      so the OLDEST committed group drains while the NEWEST issues -> back-to-back wgmma across
      K-slabs (the overlap, attacking share (B)). NST=2 clamps to wait<0> (well-formed).
  D5  setmaxnreg PRODUCER/CONSUMER SPLIT (M1, Step 4). 384-thr CTA = 1 producer WG (warpgroup 0,
      setmaxnreg.dec 40, TMA+mbar only, mbar empty[]-gated streaming) + 2 consumer WGs
      (setmaxnreg.inc 232, the wgmma). UNBLOCKED at the 128x128 tile's 64-reg accumulator
      (w10_lib.h L345) — HALF the 128x256 tile's 128 regs/thread that made ptxas reject
      setmaxnreg in W12 (C7507). FALLBACK -DW16_PRODUCER_WG=0 compiles a single-elected-thread
      producer (the W10 H1 path, 256 thr, 2 CTA/SM already) + D3/D4 software-pipeline only —
      the SAFE PARTIAL if ptxas/occupancy rejects the 384-thr 2-CTA/SM split.
  + gemm_w16b = OP-21B (keep the W10 decode band, register-double-buffer the wgmma overlap, no
    M3 dependency) for the D1-floored path. Always builds; lower ceiling (decode still gates).
