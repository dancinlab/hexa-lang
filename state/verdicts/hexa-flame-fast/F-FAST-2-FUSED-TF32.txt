The fused step = ONE persistent cooperative kernel, all 4 phases device-resident across
grid.sync() (tool/fast2/fast2_fused_step.cu):
  PHASE 0  fwd conv-GEMM   H = A @ W        (wmma TF32/BF16 own-GEMM, OG10 convention)
  PHASE 1  FF-VALLEY glue  G = gelu(H)      (between-GEMM valley elementwise)
  PHASE 2  bwd             dW = A^T @ dG    (atomic-free, fixed ascending-K accum order)
  PHASE 3  FF-FUSED-OPTIM  W' = adamw(W,dW) (fused AdamW, elementwise)
NO atomics anywhere -> determinism. Identical device math in the fused path and the
SAME-DTYPE separate-kernel reference -> a rel-RMS difference can ONLY come from fusion,
never a formula mismatch. env HEXA_FLAME_FAST gates the opt-in fast lane.
