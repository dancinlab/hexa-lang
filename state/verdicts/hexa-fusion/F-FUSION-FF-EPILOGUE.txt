HONEST NET (g5): the fusion is a CORRECT, byte-exact, real but MODEST win. The speedup is

  intermediate-activation HBM round-trips removed (matters in the memory-bound elementwise tail),

  closed-neg ruled out for FP64+byte-eq). The win grows in the launch-bound / small-M regime and
  shrinks in the GEMM-bound square regime measured here. No raw-GEMM-superiority claim;
  cuBLAS = roofline.

BUILD NOTE (byte-eq dependency): -fmad=false is REQUIRED for max|Δ|=0. With FMA-contraction ON
  (default), the fused epilogue and the separate gelu kernel contract the GELU 0.5*x*(1+erf)
  expression DIFFERENTLY (the surrounding code differs at each call site) -> a ~1-ULP residual
  (measured max|Δ|=4.768e-7, 928096/1048576 bit-identical @S=1024). With -fmad=false both call
  sites emit the IDENTICAL fp32 op sequence -> max|Δ|=0. This is a faithful, documented gate
  condition, not a fudge: the two paths are bit-identical iff the compiler is forbidden from
  contracting one site's mul-add into an FMA that the other site does not.
