================= THE FP16 GMMA LAYOUT RE-DERIVATION (differs from TF32 8x4) =================
TF32 wgmma is .k8 with an 8-row x 4-K-elem core (8*4*4B = 128B). FP16/BF16 wgmma is .k16 with
an 8-row x 8-K-elem core (8*8*2B = 128B core matrix). The re-derived f16 INTER index:
  gmma_phys16(s,k) = ((strip*KCORES + kcore)*64) + (s&7)*8 + (k&7),  strip=s>>3, kcore=k>>3,
                     KCORES = K_TILE/8.   (8-wide cores, 2-byte elems.)
SWIZZLE_128B for f16: a 128B row = 64 f16 = 8 granules of 8 f16 (granule = 16 B). On-GPU
MODE 2/3 dumps (unique-id, this H100) MEASURED the law = TEXTBOOK g_phys = g XOR (r&7) on the
8-f16 granule index g=c>>3, row-preserving, atom-major (8 rows x 64 f16 = 512 f16/atom):
  pr=0 mask 0  pr=1 mask 1 ... pr=7 mask 7  (verbatim from the dump — identical structure to
  the W10 FP32 law, just 8-element granules instead of 4-element). Composed decode (proven):
    A: atom*512 + (m&7)*64 + ((k>>3)^(m&7))*8 + (k&7)
    B: k*64 + ((n>>3)^(k&7))*8 + (n&7)   (box {64(N),16(K)} for the slab, contig=N)
