OBJECTIVE
  A STANDING per-PR smoke gate that re-exercises the multi-target cross-emit
  path proven one-time in SELFHOST-NEXT and ASSERTS the actual relocation
  entries (not merely "an object was produced"), then LINK+RUNs each target
  under the host toolchain (x86_64 natively, aarch64 under qemu):
    • arm64 ELF page-reloc PAIR  (#2562 R_AARCH64_ADR_PREL_PG_HI21
                                        + R_AARCH64_ADD_ABS_LO12_NC)
    • x86_64 ELF RIP-rel reloc   (#2563 R_X86_64_PC32)
    • linux-arm64 data-reloc program emit→assemble→link→RUN under qemu (#2603)

EMIT PATH (portable — needs only a released `hexa`, NOT the native gen2_fix)
  Each in-tree harness drives the SAME serializers the compiler uses
  (pack_lir_arm64_elf + serialize_elf_arm64 / pack_lir_x86_64 +
  serialize_elf_x86_64) and writes THREE objects:
    (A) data  — main ADRP/ADD (arm64) / lea-RIP (x86) of .rodata + .data
                → the reloc PAIR / PC32 against BOTH sections.
    (B) exit7 — text-only baseline (no data reloc).
    (C) start — runnable freestanding _start (write(1,str,3)+exit(7)) whose
                .rodata string ref USES the data reloc → if the reloc resolves
                to the right runtime address, stdout=="hi" rc==7.

HONEST CAVEATS
═══════════════════════════════════════════════════════════════════════════════
  • The REAL reloc-assert + qemu/native run is verified on summer (x86_64 Linux
    with the aarch64-linux-gnu cross-binutils + qemu-aarch64-static); aiden
    carries the identical toolchain. On macos-latest (the hosted CI runner) the
    gate emits all objects (canary PASS) but reports the reloc-assert + run legs
    NEUTRAL — macOS has no GNU readelf and Mach-O `ld` rejects -nostdlib. This is
    the SAME exit-2-neutral-on-the-host-that-can't shape as the #2600/#2605
    sister gates; it is NOT green-by-skip (the emit half runs on every host, and
    the assert/run half runs REAL on any Linux host with the toolchain).
  • To run all legs REAL in CI, add a self-hosted x86_64-Linux runner with the
    aarch64 cross-binutils + qemu-aarch64-static (the summer/aiden profile) and
    target the job at it (or set HEXA_CROSSEMIT to a released ./hexa there).
  • The arm64 page-reloc emit uses the asm-free in-tree serializer path
    (pack_lir_arm64_elf → serialize_elf_arm64), reaching the SAME #2562 reloc
    pair that the SELFHOST-NEXT CROSS-EMIT-DATA verdict reached via the
    aprime_cc --emit=asm + GNU-as fixup path — but with no aprime_cc dependency,
    so the smoke runs on any host with a released `hexa`.
