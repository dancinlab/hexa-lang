GOAL: close the BENCH-12/13 D=2048 single-wave ~1.36x residual off cuBLAS-TF32 with the LAST
identity-preserving lever — per-CTA wgmma MAINLOOP tuning. cuBLAS tunes its inner loop (epilogue

the residual is NOT the scheduler (rasterization/persistent = no-ops at single wave) and NOT
tail-quant @2048 — it is the per-CTA wgmma mainloop efficiency. CRITICAL (g5): unlike split-K
(which changes FP32 accumulation order -> breaks bit-exactness), inner-loop microarch tuning
changes only SCHEDULING/overlap (WHEN a wgmma issues, WHEN a fragment stores), NOT the per-tile
FMA accumulation order or the values -> the result MUST stay byte-identical.

MECHANISM (self/native/wgmma/wgmma_tf32_b14.cu, MODE 8 = gemm_og17_b14; driver bench14_run.sh):
  Clones the BENCH-12/OG16 descriptor-direct 128x128 per-tile math VERBATIM (route-a gmma-INTER
  pre-laid global, NO decode band, 2 accumulators d0/d1, 2 CTA/SM at NST<=3). The two net-new
  inner-loop levers:
   L1 DEEPER wgmma-group PIPELINE (dual-issue depth PDEP). OG16/MODE4 does wgmma.wait_group 0
      (FULL drain) + __syncthreads EVERY K-slab -> the next slab's wgmma cannot ISSUE until the
      current slab's tensor cores fully drain. OG17/MODE6 relaxed this to wait_group 1 (1 group
      in flight). MODE 8 GENERALIZES to wait_group PDEP: each K-slab is its own commit_group and
      PDEP groups are kept in flight, so slab ki's wgmma issue overlaps the tensor-core drain of
      slabs ki-1..ki-PDEP. Needs NST>=PDEP+1 ring buffers so the PDEP+1 live slabs read DISTINCT
      smem (the per-buffer mbarrier already gates reuse; the prefetch only overwrites a buffer
      `stages`=min(NST,nks)>=PDEP+1 slabs ahead, so an in-flight slab's smem is never clobbered).
      PDEP=0 == OG16 full-drain; PDEP=1 == OG17 MODE6; PDEP>=2 == NET-NEW. Host clamps PDEP<=NST-1.
   L2 OVERLAPPED + VECTORIZED EPILOGUE. The trailing wait_group 0 drains the last live group; the
      C-store then issues .v2.f32 128-bit-half vector stores for the contiguous gmma col-pair
      (idx=c*4+r*2+{0,1}, columns col0/col0+1 contiguous in gD) — halving the store-instruction
      count and giving the compiler the final drain to hide store-address math behind. Byte-
      identical targets to MODE 4/6 (same d0/d1 fragment layout, just 2 floats per instruction).
  PDEP only deepens the wgmma SCOREBOARD, not the smem ring -> occupancy unchanged at a given NST.
