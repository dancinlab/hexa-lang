WHAT
----
`__hx_make_val(tag, payload) -> HexaVal` — the symmetric WRITE-half of the
existing `__hx_tag(v) -> int` reader. WRITES a {tag, payload} 16-byte HexaVal
from two raw int64 words, WITHOUT going through hexa_int/hexa_float/… boxing
(which would force a fixed tag and lose the caller's intended tag). This lets a
raw payload word loaded from an array slot be re-stamped with its REAL element
tag — the NAMED unblocking lever from array r1 (#3484) and B1 (#3480) for
B4/B5 element returns and the nanbox.hexa file-reduction.

SCOPE (ADD-only, mirrors the existing __hx_tag / __hx_payload_* leaves, c10)
---------------------------------------------------------------------------
1. compiler/check/bind.hexa — `__hx_make_val` added to the __hx_* allowlist.
2. compiler/codegen/arm64_darwin.hexa — STMT_CALL leaf. Both args int-boxed,
   loaded into DISJOINT pairs (x0:x1, x2:x3 — _hv_load clobbers its pair as
   scratch); lo = tag word (x1), hi = payload word (x3); stp. NO `bl`.
3. compiler/codegen/x86_64_linux.hexa — STMT_CALL leaf + new helper
   `_x86_hv_store_leaf_tagreg` (register tag, not const). payload word → r10
   (the dst home/spill reg), tag word → r11 → tag-slot via _x86_store_tag_reg.
   first→r10/second→r11 disjoint ordering (proven by payload-arith). NO `call`.
   r10/r11 are scratch (pool = rbx/r12-r15), so the dst home reg is never r11.
4. self/codegen.hexa — C-transpile:
   ((HexaVal){.tag=(HexaTag)HX_INT(t), .i=HX_INT(p)})
   (.i = the int64 union member of runtime.h HexaVal_; HX_INT reads the
   int-boxed argument payload.)
