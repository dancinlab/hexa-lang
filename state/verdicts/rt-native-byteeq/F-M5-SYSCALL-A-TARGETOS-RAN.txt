1. WHAT LANDED (ADD-only, c10)
================================================================================
`__hx_target_os()` — a 0-arg leaf intrinsic returning an int HexaVal compile-time
OS constant, value chosen by the PER-TARGET backend (matches self/rt/syscall.hexa:
__TARGET_OS__==0 ⇒ linux, ==1 ⇒ darwin):
  · compiler/check/bind.hexa        — whitelist "__hx_target_os"
  · compiler/codegen/x86_64_linux.hexa  — `__hx_target_os()` → mov r10,0 +
       _x86_hv_store_leaf (const-int HexaVal 0 = linux). Mirrors __hx_syscall0.
  · compiler/codegen/arm64_darwin.hexa  — `__hx_target_os()` → movz x1,#1
       (payload=1=darwin) + movz x0,#0 (tag=TAG_INT) + _hv_store_dst. Mirrors
       __hx_tag.
No `bl`/`call`, no payload load — pure immediate. The compiler source NEVER calls
__hx_target_os, so self-emit is unchanged ⇒ gen3≡gen4 preserved (CI selfhost-
byteeq-real is the authority; read-half added __hx_tag/__hx_make_val the same way).
