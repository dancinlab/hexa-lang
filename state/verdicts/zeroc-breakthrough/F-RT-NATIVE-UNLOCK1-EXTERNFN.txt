F-RT-NATIVE-UNLOCK1 — extern-fn FFI fix: body-less `extern fn` → undefined external (not stub)
date: 2026-06-16   domain: RT-NATIVE   unlock: UNLOCK-1 (Z3 arena FFI blocker)

ROOT CAUSE (located): compiler/parse/parser.hexa:parse_extern_fn_item synthesized an EMPTY
Block body for a body-less `extern fn` (kind ItemKind::Fn) → hir_to_mir lowered it to an MFunc
with empty body → arm64_darwin emitted a VOID-returning stub (`_malloc: movz x0,#4 ; ret void`).
So `extern fn malloc(...)` became a stub returning void → arena got a void/NULL ptr → segfault
(the Z3 blocker, F-RT-NATIVE-Z3-Z2a-Z2b-IMPL).

FIX (2 files, self-host codegen):
  - parser.hexa: when an `extern fn` has NO body, append annotation `__extern_decl`.
  - hir_to_mir.hexa: the ITEM_FN loop skips MFunc emission for `__extern_decl` items → the
    symbol stays an UNDEFINED external (linked from libc/runtime), calls still emit `bl <name>`.
  - build_aprime.sh: 2 Z2a smoke-step fixes surfaced (restore the runtime_core.c include only
    when runtime_hi_gen.c still exists; smoke links $ZEROC_RT_HI_OBJ).

VERIFICATION (c2, captured):
