KEY FEASIBILITY CORRECTION vs M4 inventory
------------------------------------------------------------------------
M4 said "rt_null_coal hexa impl ALREADY EXISTS; needs only HX_IS_VOID/HX_IS_STR
tag preds (exist)". It DOES exist — but ONLY in self/rt/core.hexa, which is the
DORMANT rt_target=="rt" migration scaffold (cg_rt_target() is hardcoded "c",
rt_symbols.hexa: core "deferred to last"). That copy is NOT in the linked
runtime object set, so a core-side `extern rt_null_coal` would have been an
UNDEFINED SYMBOL at link under HEXA_HAS_HEXA_RT_STDLIB. The real work was
adding rt_null_coal to the LINKED set (stdlib/runtime/numeric.hexa) — the same
object set that defines the live rt_len/rt_map_keys this PR neighbors it with.

RECURSION SAFETY
------------------------------------------------------------------------
rt_null_coal uses only typeof() / byte_len() / byte_at() — none re-enter
hexa_null_coal. `byte_at` lowers to hexa_str_byte_at (raw byte read, C, no
null-coal call). No infinite-recursion path. (Contrast: the M4 substring /
char_code_at "already-exists" leaves DO have recursion traps — see M5 notes.)

METHOD (real RUNEQ — not self-judge; LOCAL on mini, no ghost/pool)

CASE COVERAGE
------------------------------------------------------------------------
  void        : -> b (HX_IS_VOID arm).
  empty       : "" -> b (byte_len==0 arm == C [0]=='\0' for NUL-term empty).
  str/onechar : non-empty -> a.
  int0/int42  : non-string non-void scalar -> a (both guards fall through).
  float0      : 0.0 -> a (NOT coalesced — C only voids/empties).
  boolfalse   : false -> a (bool is neither void nor string).
  arr/emptyarr: array (incl []) -> a (C empties STRINGS only, never arrays).
  utf8        : "한글" multibyte -> a.
  nullead     : chr(0)+"tail" -> b — the leading-NUL edge: port's byte_at(0)==0
                arm reproduces C's HX_STR(a)[0]=='\0' (a perf-31 length-header
                string carries an embedded leading NUL with byte_len>0). MATCH.

KNOWN NON-EXERCISABLE EDGE
------------------------------------------------------------------------
The C `HX_STR(a)==NULL` sub-arm has no hexa analog. The `??` operator never
produces a TAG_STR HexaVal with a NULL backing pointer (hexa_str/intern always
allocate), so the arm is dead on the live path — not a divergence.
