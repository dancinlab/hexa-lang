WHAT THE FLIP DOES (tool/promote_selfhost.sh) — exact swaps
  HARD PRECONDITION (both tiers): re-runs selfhost_parity_gate.sh; if it fails,
  NOTHING is installed/flipped, exit 1.
  tier 1  `install`  (REVERSIBLE, default UNTOUCHED):
     - cp gen3,hexa_ld,rt.o -> $HX_HOME/self/native/selfhost/{gen3,hexa_ld,rt.o}
     - write launcher $HX_HOME/bin/hx-selfhost (exec's the slot gen3)
     - default hx/hexa UNCHANGED; opt-in via `hx-selfhost <args>`.
  tier 2  `install --default --i-have-reviewed-parity`  (REVERSIBLE):
     - mv $HX_HOME/bin/hexa.real -> hexa.real.pre-selfhost.<ts>   (BACKUP)
     - ln -sf $HX_HOME/bin/hx-selfhost  $HX_HOME/bin/hexa.real    (SYMLINK swap)
     - REFUSED unless BOTH --default AND --i-have-reviewed-parity AND green gate.
  REVERSIBILITY:
     - tier 1: fully reversible (delete slot+launcher; nothing else changed).
     - tier 2: REVERSIBLE via `promote_selfhost.sh --revert` (rm symlink, mv the
       hexa.real.pre-selfhost.<ts> backup back). Reversible as long as the backup
       is retained. The only "not-trivially-undoable" bit = if the backup file is
       later deleted during a soak window; runbook says keep it until soak passes.
  NOT-A-PR: tier 2 mutates an on-disk launcher in $HX_HOME OUTSIDE the repo, per
  host. No PR can carry it; it is a host-local irreversible-by-policy action needing
  human ack. THIS is why the lane does not perform it.
