MISCOMPILE-ZERO — codegen perf-stability baseline + budget
==========================================================

Milestone : codegen perf-stability baseline + budget — record the native
            compiler's emit cost (wall + object size) as a tracked baseline so
            a future codegen change that regresses perf is caught, complementing
            the correctness gates already in place (miscompile-zero #2534,
            determinism #2538, class tests #2548, diff-fuzz #2557).

Harness   : tool/codegen_perf_budget.sh   (modes: baseline | check)
Baseline  : tool/codegen_perf_baseline.tsv (committed, REAL measured numbers)
Corpus    : self/test/miscompile_zero/c1..c10 (read-only; shared with the gates)
Compiler  : graduated native self-host gen2_fix
            (ghost 192.168.50.150, ~/dancinlab/selfhost-work/gen2_fix, 1.96 MB)
Host      : ghost macOS arm64 (Darwin 25.5.0, bash 3.2.57) — REAL, not invented
Target    : arm64-apple-darwin
Method    : native --emit=obj per program, 5 timed runs (1 warmup) → median wall
            (real, ms) + emitted object byte-size. Budget: obj-size +5%,
            wall +50% (CI-noise tolerant). Exit 0 ok / 1 regression / 2 infra
            (canary 0-byte ⇒ CI-neutral, mirrors miscompile_zero_gate.sh).

g63 discrimination proof (both directions)
------------------------------------------
 + positive control: check vs self ⇒ PASS, exit 0 (above). Object sizes match
   the committed baseline byte-for-byte; wall medians within the +50% budget.
 - negative control: a baseline row tampered to shrink c7's expected size
   (3544 → 1000) ⇒ the REAL 3544-byte object exceeds the +5% cap (1050):
     FAIL  c7_recursion_arrays    size=3544>cap1050(base1000 +5%)
     perf-budget: FAIL — codegen emit-perf regression beyond budget
     REAL_RC=1
   The budget therefore actually trips (exit 1) on a real size growth — it is
   not a no-op green.

CLASSIFICATION (CI-neutral, mirrors tool/miscompile_zero_gate.sh)
----------------------------------------------------------------
  exit 0  baseline written / check within budget — perf floor held.
  exit 1  check mode ONLY: a program's object grew > +5% or median wall
          grew > +50% vs the committed baseline — real measured regression.
  exit 2  SETUP/INFRA — canary 0-byte (env cannot native-emit) or baseline
          missing/malformed. NOT a perf regression; safe in a CI runner that
          lacks the graduated native emitter.

This is the PERF axis of MISCOMPILE-ZERO. It does NOT inspect correctness
(ENCODE-MISS / udf) — that is owned by tool/miscompile_zero_gate.sh. It tracks
emit COST as a regression budget, complementing the locked correctness gates.
